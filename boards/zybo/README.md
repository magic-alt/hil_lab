# Zybo Zynq-7010 secondary FPGA-Lite target

This directory is reserved for the original Zybo (XC7Z010), not Zybo Z7. It should reuse generic FPGA-Lite capture/generator/plant cores from Track C and add only board-specific clock, XDC, top-level and electrical documentation.

AX7010 remains the first qualified Track C board. Do not fork reusable RTL here.
